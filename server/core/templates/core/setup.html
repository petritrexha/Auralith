Set up the Claude Code plugin

About 3 minutes. Code diffs leave your machine: they go to this LearnLoop server and to Anthropic's API. Secret files (.env, keys) and common credential patterns are removed on your machine first, and only a short snippet is stored per card.

{% else %}

Your current token starts with {{ profile.token_prefix|default:"(none)" }}…. Tokens are stored hashed, so we can't show it again. Lost it? Make a new one (the old one stops working):

{% csrf_token %}
{% endif %}
2 · Install the plugin

In Claude Code, add the LearnLoop marketplace and install the plugin (use your team's repo URL or local folder):

/plugin marketplace add <path-or-git-url-of-the-learnloop-repo>
/plugin install learnloop@learnloop

Claude Code will ask for the server URL and your token when you enable it:

Server URL: {{ server_url }}
Token:      (the token from step 1)

Prefer environment variables? Set LEARNLOOP_URL={{ server_url }} and LEARNLOOP_TOKEN=… in your shell profile instead. For local development: claude --plugin-dir ./plugin.

3 · Test the connection

Start a new Claude Code session (the plugin pings on start), then click:

{% if last_ping %}Last seen {{ last_ping|timesince }} ago{% else %}Not connected yet{% endif %}

4 · Code as usual, then train it

When the agent finishes a turn and something new came up, a LearnLoop card appears in the terminal and in your feed. Mark cards "I know this" or "Mute" so it stops repeating itself.
